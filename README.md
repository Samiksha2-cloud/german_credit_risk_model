# German Credit Risk Model

## Why this project
I'm a fresher preparing for AI Engineer / Data Analyst interviews targeting
banks and MNCs in Mumbai. I chose the German Credit dataset because it's a
classic, well-documented credit risk problem that lets me practice the full
ML workflow on clean, small data — EDA, feature engineering, imbalance
handling, cost-sensitive thresholding, and explainability — all concepts
banks specifically ask about in interviews.

## Problem
Predict whether a loan applicant is a good or bad credit risk, using 20
applicant attributes (financial history, employment, demographics).
